So entsteht das Ranking

  1. Für jede Kennzahl bekommt jeder Titel sein Perzentil: den Anteil der Titel, die schlechter abschneiden. Bei Multiples ist niedriger besser, bei Renditen und Margen höher.
  2. Der Value-Score ist der Mittelwert der Value-Perzentile, der Quality-Score der Mittelwert der Quality-Perzentile. Fehlen zu viele Kennzahlen, gibt es keinen Teilscore.
  3. @if (params().value_weight; as weight) { Der Composite gewichtet beide, heute {{ weight | pct: '1.0-0' }} Value und {{ 1 - weight | pct: '1.0-0' }} Quality. Danach richtet sich der Rang. } @else { Der Composite gewichtet beide nach den Gewichten des Profils. Danach richtet sich der Rang. }
  4. Ein Titel mit hohem Value- und niedrigem Quality-Score bekommt den Hinweis „Value-Trap?“. Die Schwellen legt das Profil fest.
  5. Das KGV zählt nicht, weil Einmaleffekte den Gewinn stark verzerren. Das Ranking ist eine quantitative Vorauswahl und keine Anlageempfehlung.
